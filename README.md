# ico-vid

Atelier de la chaîne vidéo pixel art de **@yehz** (YouTube, TikTok, Instagram) : bible graphique, palette `ico-pixel-32`, modèles et presets EffectCraft, outils Python de montage et de contrôle, épisodes en cours, plan de l'« usine ».

Le travail est fait à deux avec des agents IA : **Claude Code** (orchestrateur, voir [`CLAUDE.md`](CLAUDE.md)) et **Antigravity / Gemini** (avis et direction artistique, voir [`GEMINI.md`](GEMINI.md)). Organisation : [`agents/README.md`](agents/README.md).

- Installer sur une nouvelle machine : [`INSTALLATION.md`](INSTALLATION.md)
- Décisions validées : [`plans/decisions.md`](plans/decisions.md)
- Bible : [`bible.md`](bible.md) · journal des gênes : [`ce-qui-m-a-gene.md`](ce-qui-m-a-gene.md)
