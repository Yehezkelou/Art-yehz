## Résultat

40 tests verts (32 existants + 8 nouveaux). `verifier_pixels.py --echelle 1` VERT sur les 24 images de la démo.
**Temps : ~0,7 s de démarrage puis ~20 ms par image (270×480), soit ~1,1–1,3 s pour 24 images.**

## Contrat tel qu'implémenté
Commande : `node outils/rendu3d/rendu3d.mjs --scene <f.mjs> --out <dossier> --debut <s> --fin <s> [--ips 24]
[--largeur 270] [--hauteur 480] [--fond transparent|RRGGBB] [--params '<json>'] [--images 0,5,9]`
(aussi `--cle=valeur`). Image i = instant `debut + i/ips`, `round((fin - debut) × ips)` images, fin exclue. Code 0
réussi, 1 échec du rendu (JSON `{"ok": false, "erreur": …}` sur stdout), 2 erreur d'arguments.
Résumé : `ok, scene, out, largeur, hauteur, ips, debut, fin, images_total, images, premiere, derniere, fond,
lumiere_defaut, three, gpu, navigateur, secondes_preparation, ms_par_image, secondes_total`.

Scène : `export default function creer(THREE, outils, params)` (peut être async) → `{ scene: THREE.Scene, camera,
update(t) }` (update facultatif, peut être async). Servie depuis son dossier (imports relatifs de ce dossier,
`"three"` et `"three/addons/"` disponibles ; pas d'import vers un dossier parent).

`outils` (objet gelé) :
```
palette                      // 32 chaînes "#RRGGBB" majuscules, ordre du .hex ; palette[0] = couleur 1 = "#0E0D18"
couleur(i)                   // i entier 1–32 → THREE.Color ; erreur sinon
materiau(i, {ombre = "toon"})// "toon"|true → MeshToonMaterial (gradientMap 3 paliers 90/170/255, Nearest)
                             // "lambert" → MeshLambertMaterial ; "plat"|false → MeshBasicMaterial (couleur exacte)
voxelTexte(texte, {cube = 1, profondeur = 1, couleur = 8, ombre = "toon"})
                             // THREE.Group centré sur l'origine ; enfants = un Group par caractère
                             // (name = caractère, userData {caractere, index}, position x = centre du glyphe),
                             // petits-enfants = un Mesh BoxGeometry(cube, cube, cube*profondeur) par « # »
hasard(graine)               // mulberry32 → () => nombre dans [0, 1)
lisse(u)                     // smoothstep, u borné à [0, 1]
entre(t, t0, t1)             // lisse((t - t0)/(t1 - t0)) ; échelon si t1 <= t0
ressort(u)                   // 0 si u <= 0, 1 si u >= 1, sinon 1 - cos(2,5πu)·e^(-4u)·(1-u) (pic ≈ 1,12)
largeur, hauteur, ips        // de la ligne de commande
```
Rendu : `WebGLRenderer({antialias: false, alpha: true, premultipliedAlpha: false, preserveDrawingBuffer: true})`,
pixelRatio 1, `setSize(largeur, hauteur, false)`, sortie sRGB par défaut, pas de tone mapping ; `transparent` =
clear alpha 0, sinon clear opaque de la couleur donnée. Quantification dans Node : alpha < 128 → (0,0,0,0), sinon
couleur de palette la plus proche (RGB euclidien), alpha 255.

Python : `rendu3d.rendre(scene, sortie, debut, fin, ips=24, fond="transparent", params=None, largeur=270,
hauteur=480, images=None, delai=None)` → dict du résumé ; lève `rendu3d.ErreurRendu`. Aussi `trouver_node()`,
`dependances_presentes()`, `commande(...)`. CLI : `python3 -I outils/rendu3d.py <scene> <sortie> --debut --fin [...]`.

## Ajouts hors contrat (compatibles)
- Sans lumière dans la scène : ambiance 0,9 + soleil 2,2 en (-3, 5, 6) ajoutés (signalé par `lumiere_defaut`).
- `Math.random` de la page est remplacé par un générateur à graine fixe avant `creer` (three tire des UUID ; une
  scène qui l'utiliserait quand même resterait reproductible), mais la règle reste `outils.hasard`.
- `--fond` ne s'applique que si la scène ne pose pas `scene.background` (la scène a le dernier mot).

## Ce qui reste incertain
- Reproductibilité vérifiée sur une même machine (et AMD vs NVIDIA pour une image) ; un autre GPU ou une autre version
  de Chrome peut décaler quelques pixels au bord d'un palier de quantification. Pour une vidéo, rendre toutes ses
  séquences sur la même machine.
- Non testé sous WSL/Linux (détection `google-chrome`/`chromium` dans le PATH prévue, sans GPU = SwiftShader
  probable, peut-être `--enable-unsafe-swiftshader` à ajouter).
- Le rendu 3D ne respecte pas « positions arrondies / échelles entières » au sens sprite : la conformité est
  garantie seulement sur la palette et l'alpha (le test `--echelle 1` le confirme). Les arêtes des cubes en rotation
  font des escaliers d'un pixel, sans flou.
- Les dégradés toon ramenés à la palette peuvent changer de teinte (un jaune ombré peut tomber sur un brun) : à
  régler scène par scène avec la couleur choisie ou `ombre: "plat"`.
- `npm ci` à lancer une fois par clone (`node_modules` ignoré par git). three (MIT) et puppeteer-core (Apache-2.0)
  ne vont pas dans `assets/` : pas d'entrée au manifeste.
