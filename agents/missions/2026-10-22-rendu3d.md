# Mission : outil de rendu 3D pixel art (three.js → séquence PNG palette ico-pixel-32)

- **Date** : 2026-10-22
- **Agent** : outilleur
- **Mode** : écriture (fichiers listés ci-dessous seulement)
- **Étape du plan** : pixel-04-binaire3d (refonte de pixel-03-binaire avec de la 3D, demandée par @yehz le 22/10)

## But
Pouvoir rendre une scène three.js image par image, en pixel art conforme à la bible (palette ico-pixel-32,
pixels pleins, transparence tout-ou-rien), en séquence PNG que les compositeurs Python d'épisode superposent.

## Contexte à lire
- `CLAUDE.md` (règles pixel : échelles entières, palette ico-pixel-32, pas de flou ni de semi-transparence)
- `bible/palette/ico-pixel-32.hex` ; `assets/polices/ico5x7.py` (police pixel 5×7) ; `outils/png.py`, `outils/chemins.py`
- `pixel-03-binaire/.montage/composer.py` (le compositeur qui consommera les séquences)
- skills `.claude/skills/threejs-fundamentals`, `threejs-geometry`, `threejs-materials` (three.js r186)

## Contrat (à respecter tel quel : d'autres agents écrivent les scènes en parallèle sur ce contrat)
- Commande : `node outils/rendu3d/rendu3d.mjs --scene <fichier.mjs> --out <dossier> --debut <s> --fin <s>
  [--ips 24] [--largeur 270] [--hauteur 480] [--fond transparent|RRGGBB] [--params '<json>'] [--images 0,5,9]`
  → `<dossier>/f_0000.png …` (RGBA 8 bits, numérotées depuis 0 = instant `--debut`), et un résumé JSON sur stdout.
- Module de scène (ESM) : `export default function creer(THREE, outils, params) { … return { scene, camera, update(t) } }`
  - `update(t)` reçoit le temps en secondes (absolu, celui de `--debut`…) ; tout doit être déterministe
    (pas de Math.random ni d'horloge : `outils.hasard(graine)` renvoie un générateur reproductible).
  - `outils.palette` : les 32 couleurs (`"#1D1B2E"` …, index 1–32 dans l'ordre du .hex) ; `outils.couleur(i)` → THREE.Color.
  - `outils.materiau(i, {ombre})` : matériau mat lisible en pixel art (MeshLambert ou MeshToon, couleur i de la palette).
  - `outils.voxelTexte(texte, {cube=1, profondeur=1, couleur=8})` : THREE.Group de cubes (un cube par « # » des
    glyphes ico5x7, espacement 1 colonne), centré sur l'origine ; caractères absents → erreur claire.
  - `outils.lisse(u)`, `outils.entre(t, t0, t1)` (smoothstep borné), `outils.ressort(u)` (dépassement amorti, pour les pops).
- Rendu : WebGLRenderer sans antialiasing, pixelRatio 1, toile `largeur×hauteur` ; chaque image est ramenée à la
  couleur de palette la plus proche (RGB euclidien), alpha < 128 → 0 sinon 255 (aucune semi-transparence).
  Fond `transparent` = alpha 0 hors des objets.
- Navigateur : Chrome ou Edge déjà installés (détection automatique sous Windows, surcharge `ICO_CHROME`), via
  `puppeteer-core` (aucun navigateur téléchargé). three et puppeteer-core en versions exactes dans
  `outils/rendu3d/package.json` (three 0.186.x), `node_modules` ignoré par git.
- Enveloppe Python : `outils/rendu3d.py` (fonction `rendre(scene, sortie, debut, fin, ips=24, fond="transparent",
  params=None)` + ligne de commande) qui trouve node et lance l'outil, pour les compositeurs d'épisode.
