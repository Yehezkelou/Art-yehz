## Contrat
1. `outils/vox.py` (Python pur, sans dépendance) :
   - `Modele(lx, ly, lz)` : grille de voxels, `m[x, y, z] = i` (i = index palette 1–32, 0 = vide) ; axes :
     x vers la droite, y vers le haut, z vers l'avant (vue de face = on regarde vers −z) ;
   - `m.boite(x0, y0, z0, x1, y1, z1, i)`, `m.calques(lignes_par_y, legende)` (calques ASCII, un calque par
     hauteur y, chaque calque = lignes z de caractères x, légende caractère → index), `m.miroir_x()`, `m.copier()` ;
   - `ecrire_vox(chemin, modeles)` (un ou plusieurs modèles dans le fichier, palette ico-pixel-32 dans le chunk
     RGBA aux index 1–32, le reste noir) et `lire_vox(chemin)` → liste de `Modele` ;
   - `apercu(chemin_png, modele, vue="trois-quarts")` : image PNG de contrôle (projection simple, palette) ;
   - `palette_magicavoxel(chemin_png)` : la palette 256×1 pour MagicaVoxel (→ `assets/3d/palette/ico-pixel-32-magicavoxel.png`).
2. `outils/rendu3d/voxel.mjs` (importable par les scènes via `outils.voxel`, à ajouter à l'objet `outils`) :
   - `outils.voxel.charger(chemin)` (chemin relatif à la racine du dépôt) → liste de modèles (grilles) ;
   - `outils.voxel.maillage(modele, {rampe, contour, occlusion=true, centre="bas"})` → THREE.Mesh :
     maillage glouton (faces internes retirées), couleur **exacte** de la palette par face selon une rampe
     `{dessus, face, cote, dessous}` dérivée de la couleur du voxel (table par défaut : pour chaque index, ses
     voisins plus clairs / plus sombres dans la même rampe de 4 de la palette), occlusion = un palier plus
     sombre pour les faces coincées, `contour` = arête sombre (index 1 ou 2) facultative ; matériaux non
     éclairés (aucune teinte intermédiaire possible après quantification) ; origine selon `centre`
     (« bas » = milieu du dessous, pour poser au sol) ;
   - `outils.voxel.rig(parties, rigToml)` → THREE.Group hiérarchique : chaque partie (Mesh) sur son pivot,
     `poser(nomClip, t)` pour les clips procéduraux de base `idle`, `marche`, `saut`, `parle`, `coucou`
     (angles et décalages simples, rythme 12 i/s possible via `outils.pas12(t)`), extensible ;
   - `outils.texturePixel(cheminPng)` → THREE.Texture NearestFilter sans mipmaps (style boîte texturée) ;
   - `outils.halo(rayon, couleurs)` → groupe d'anneaux plats (lueur pixel sans transparence).
3. Format du rig `<nom>.rig.toml` (lu côté Node : TOML simple ou JSON équivalent à documenter) :
   `[parties.tete] fichier = "tete.vox", parent = "corps", pivot = [x, y, z]` (en voxels), `echelle` globale.
4. Démo : `outils/rendu3d/exemples/voxel_demo.py` (fabrique un petit personnage chibi de démonstration en 6
   parties + son rig) et `exemples/voxel_demo.mjs` (le fait marcher 2 s en orbite) — démo seulement, pas un
   asset de chaîne.
